Calendar & Tasks · One Google account

One-time setup: create a Google OAuth client for this dashboard.

  1. In Google Cloud, create or select a project.
  2. Enable the Google Calendar API and Google Tasks API.
  3. In Google Auth Platform, configure Branding and Audience. For a personal testing app, add your Google email as a test user. Under Data Access, add the calendar.readonly, tasks (Tasks editing access), openid, and profile scopes.
  4. Under Clients, create a Web application client. Add as an authorized JavaScript origin.
  5. Paste the client ID below. No client secret is needed.

Open Google Cloud setup ↗

Stay connected

To renew Google access automatically, add this Authorized redirect URI to your Google OAuth Web client:

http://localhost:4173/oauth/google/callback

Download that client's credentials JSON from Google Cloud and choose it below. Credentials and refresh tokens are encrypted for your Windows account. Do not paste the client secret into chat.

Google apps in Testing mode usually require authorization again after seven days. Revoked access also requires reconnecting.
